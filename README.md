Cohort-integral forecaster: reads the house's Exophase reads of the GTA VI trophy page before the case checkpoint and forecasts each trophy's earn rate at the target as five quantiles (5%, 25%, 50%, 75%, 95%). Deterministic, offline, no network, no model calls.

## Run it

```sh
python3 main.py
```
