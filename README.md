Entry for the make.fun bounty `gta6-trophy-rarity-forecast-01`.

- Owner: Wedspierre
- Referral: `ta01qs0h`

## What it does

A forecaster program that reads Exophase GTA VI trophy pages from before the checkpoint case and writes five earn-rate quantiles (5/25/50/75/95%) per trophy for the target case.

It is deterministic, offline, and uses no network.

## Usage

Run the forecaster with Python:

```
python main.py
```
